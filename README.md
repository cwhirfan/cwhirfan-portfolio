# Harith Irfan — Data Analyst Portfolio

A responsive dark futuristic portfolio template tailored to a Data Analyst / BI profile.

## Files
- `index.html` — content and page structure
- `styles.css` — dark futuristic styling and responsive layout
- `script.js` — reveal animation and mobile navigation

## Customize
1. Edit text directly in `index.html`.
2. Change theme variables at the top of `styles.css`.
3. Replace the project descriptions/tags with screenshots or links when available.
4. Add your resume download by placing your PDF in this folder and adding a button such as:
   `<a href="resume.pdf" class="btn btn-ghost">Download Resume</a>`

## Run locally
Double-click `index.html` or open the folder with VS Code + Live Server.


## Adding dashboard & speaker images

Create an `assets` folder beside `index.html`, then add images using these filenames:

- `dashboard-oms.jpg` — Online Marking System / examination dashboard
- `dashboard-shtj.jpg` — Sistem Hasil Tanah Johor dashboard
- `dashboard-other.jpg` — another dashboard you want to feature
- `speaker-superset.jpg` — Apache Superset training photo
- `speaker-python.jpg` — Python / Selenium training photo
- `speaker-event.jpg` — another workshop, presentation, or speaking photo

The website automatically shows a designed placeholder if an image has not been added yet. For best results, use 16:9 dashboard screenshots and portrait/vertical photos for speaker cards.

## About section portrait
Add your transparent-background portrait as:

`assets/profile-harith.png`

For the best blend with the design, use a PNG/WebP with a transparent background, portrait orientation, and some empty space around the shoulders/head. A minimum height of around 1200 px is recommended. The site automatically adds the glow, grid, floating motion, orbit elements, and data-style labels around the image.
